# FTP — a Porta plugin

Open a project that lives on an FTP or FTPS server: browse, edit and save its files as though they were here.

![The ftp page in Settings → Plugins](https://janalis.github.io/porta/screenshots/plugin-ftp.svg)

This is `janalis/porta-ftp`, one of the plugins bundled with
[Porta](https://github.com/janalis/porta), the terminal IDE for PHP. Porta
ships it already, on by default: turn it off under **Settings → Plugins**.
Install this package only to run a copy of your own, which shadows the bundled
one.

- [Documentation](https://janalis.github.io/porta/plugins/ftp/)
- [Writing a plugin](https://janalis.github.io/porta/plugins)

## Read-only

This repository is a read-only split of `plugins/ftp` in
[janalis/porta](https://github.com/janalis/porta), updated on every push.
Report issues and send pull requests
[there](https://github.com/janalis/porta).
